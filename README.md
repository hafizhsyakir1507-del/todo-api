# Todo List API

API untuk mengelola daftar tugas yang dibangun menggunakan Node.js dan Express.js.

## 📋 Fitur
- Autentikasi pengguna (Register & Login) dengan JWT
- Mengelola Todo (Buat, Baca, Ubah, Hapus)
- Paginasi, Filtering, dan Sorting daftar Todo
- Pencarian berdasarkan judul
- Log aktivitas pengguna
- Endpoint statistik yang dilindungi API Key

## 🛠️ Teknologi
- Node.js
- Express.js
- MongoDB dengan Mongoose
- JSON Web Token (JWT)
- Swagger UI — Dokumentasi API
- Jest & Supertest — Pengujian Otomatis
